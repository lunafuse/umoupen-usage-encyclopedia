Verification scope

Section titled “Verification scope”
  • Hands-on: the top menu, Panels, Show Panels, Timeline, Frame Mark, Onion Skin, and the main panels.
  • Current implementation: the built-in Help, Command names, Settings, saved data, and macOS arm64 / Windows x64 binaries in build 530.
  • Conditional: Room, Game, 3D, Online Session, License, and the results of importing and exporting external formats.
  • Unverified areas are listed at the end of each article.

Changes

Section titled “Changes”

Japanese display names

Section titled “Japanese display names”

We used the 3,446 built-in English–Japanese pairs in the build 530 executable as the canonical source for display names, then re-audited the body text, UI locations, and shortcut names in 128 user-facing files. We updated 1,887 registered key–file pairs to their corresponding Japanese display names. The number of registered English keys remaining in visible text is 0.

Each feature article retains its English-key mappings as search data. UI text not registered in the current built-in table uses the same English name shown on screen.

Settings, authentication, and diagnostics

Section titled “Settings, authentication, and diagnostics”

Reading the Settings menu explains the purpose and visibility conditions of all 58 groups: 25 File groups, 26 View groups, and 7 Panel groups.

We added the route from the File menu to My Devices to License activation and device management. Diagnostics and save-failure reports now explicitly instructs users to turn off diagnostic recording after reproducing the problem.

UI component coverage audit

Section titled “UI component coverage audit”

Separately from the article count, we check whether every control in the current UI is documented in an article body.

We assigned all 83 items in the Toolbar’s 13 groups—55 visible and 28 hidden—to feature articles one by one. Coverage includes Panel Tool, Book Margins, the 3D toolbars, color controls, the control row at the bottom of the Timeline, and buttons on addable panels.

Dedicated acceptance tables cover 23 current Panels, 3 Timeline-related views, 36 Properties states, 58 Settings groups, 10 main dialogs, 10 import route groups, 12 export-range commands, Command, Search, and Shortcuts. The public shortcut index organizes 261 default assignments into 137 user-facing rows.

Screen map

Section titled “Screen map”

We added a map dividing the current UI into 7 areas to the beginning of Browse by feature or screen. It provides routes from screen locations to existing feature articles.

Panels

Section titled “Panels”

The panel acceptance table registers 23 editing panels. In addition to each panel’s fixed controls, it covers menus by layer type, page operations, Navigator view selection, Gallery menus by asset type and drag destinations, and color controls.

Timeline, Properties, and Settings

Section titled “Timeline, Properties, and Settings”

We documented the fixed displays and controls in Timeline, Timesheet, and Storyboard Timeline; Properties states for tools, layers, and selections; and Settings and the main dialogs, organized by state.

Import, export, and shortcuts

Section titled “Import, export, and shortcuts”

We organized the entry points and supported formats for images, production files, audio, video, 3D, brushes, palettes, effects, symbols, and text. Export coverage lists conditions including range, format, size, transparency, camera, subtitles, draft layers, layers, and audio.

We compared the 222 Actions, 261 default assignments, and 16 Key Contexts in the current binary, then updated Browse by shortcut and Search.

Icons at the top of the Layers panel

Section titled “Icons at the top of the Layers panel”

The Layers panel and active layer now covers these 8 items from left to right: Add, Select, Slim, Label, Opacity, Draft, Tint, and Solo.

Tool-specific properties

Section titled “Tool-specific properties”

When you select a tool, Properties on the right switches to settings for that tool. Read and customize toolbars links to explanations for Brush, Pen, Eraser, Fill, Select, Move, Text, Ruler, and other tools.

Item names and visibility conditions were verified against the current build 530 implementation. Settings whose results remain unverified are identified at the end of their respective articles.

Peg Field

Section titled “Peg Field”

Under Advanced in Onion Skin, you can independently move, rotate, and scale the surrounding drawings to align the in-between position.

Build 530 is the first verification baseline. No features have yet been compared with older builds. Materials from older builds are not used as build 530 specifications.
