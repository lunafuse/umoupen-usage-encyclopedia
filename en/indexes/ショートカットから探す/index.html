Browse by shortcut

This page is based on the initial Umoupen Default assignments verified in Umoupen 0.9.49 build 530. The display names and assignments for additional actions were verified on macOS in 0.9.51 build 541. The same key can perform different actions depending on the current editing context. On Windows, the key corresponding to macOS ⌘ is shown as Ctrl.

If you changed the assignments, use the current values shown under Settings (gear) → More → Edit Keybinds → Help → Shortcuts.

Open Properties from Panels → Show Panels → Properties. Pressing one of the drawing-tool keys below switches Properties to the options for that Tool.

For actions with no assigned key, or buttons that are not visible on the current toolbar, use Search → Customize Toolbar to check their availability.
