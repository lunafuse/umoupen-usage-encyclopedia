Create your first animation

Section titled “Create your first animation”

Open the features you need in order, from creating a file to exporting a video.

  1. Project types and creating a new file — Choose Animation, then set the screen size and FPS
  2. Reading the Timeline — Select the layer and frame cell where you will draw
  3. Draw with the Pen — Draw the first image
  4. Blank and duplicate frames — Add the next image
  5. Change exposure length and position — Adjust how long an image appears and when it starts
  6. Onion Skin — Overlay the surrounding images while drawing an in-between
  7. Playback, looping, and playback range — Check the motion and playback range
  8. Save a project — Save the Umoupen file
  9. Export MP4 or GIF — Create a video or GIF to share

Create a comic

Section titled “Create a comic”

Open the features in order, from creating a Comic project to arranging pages and exporting a PDF.

  1. Project types and creating a new file — Choose Comic, then select a preset such as Manga, US Comic, Euro BD, or Webtoon
  2. Pages panel and page switching — Open the page list and choose the page to edit
  3. Double-page spreads, solo pages, and page margins — Choose single pages or spreads and set the margins
  4. Draw with the Brush — Draw on the selected page
  5. The Layers panel and active layer — Confirm the layer where you will draw
  6. Add, duplicate, delete, and reorder pages — Add pages and arrange them in reading order
  7. Save a project — Save the Umoupen file
  8. Export a PDF — Export selected pages or every page as a PDF
