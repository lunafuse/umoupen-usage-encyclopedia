Transitions between shots

Verification record: Umoupen 0.9.59 build 628 (2026-10-05) · Verification scope

A transition determines how the picture changes between shots. An overlap superimposes the outgoing and incoming pictures; a fade-in or fade-out gradually reveals or removes a picture. These affect the picture, while an audio fade changes volume.

Add Transition, Delete Transition, Transitions, Transition type, Wipe shape, Transition padding, Pad new transitions, Preview transition, Edit transition in Timeline, Extra frames, Ordered in, Ordered out, Set order, Set request, Use minimum, transitions between shots

Transitions such as overlaps and fades connect neighboring shots. Set the transition type and length, and record the extra animation frames needed for the connection.

Location: Storyboard Timeline (Storyboard Timeline) → right-click a shot → Add Transition

Basic steps

Section titled “Basic steps”
  1. Right-click the shot before the connection in the Storyboard Timeline.
  2. Go to Add Transition and choose a type from the list that opens.
  3. Set Transition type and Length (frames). Use Edit transition in Timeline to edit an existing transition.

When it works: The chosen type’s symbol appears in the Transition row below the Storyboard Timeline.

Transition types

Section titled “Transition types”

The Add Transition list holds eight types in two rows.

List labelMeaning
O.L.Overlap. Overlaps the neighboring shots
F.I.Fade in
F.O.Fade out
WipeWipes across the frame into the next shot
DipDips to a solid color before the next shot
FlashFlashes brightly at the cut
BlurBlurs from one shot into the next
CustomSpecify something none of the above covers

The list uses abbreviations (O.L., F.I., F.O.), while the printed storyboard uses the full name, such as Overlap.

Wipe shape specifies the wipe’s shape. Fade-in start and Fade-out end specify fade positions.

Global settings

Section titled “Global settings”

Global transition settings controls the default handling of new transitions.

ControlPurpose
Pad new transitionsAdd padding to new transitions
Pad new transitions to preserve timingAdd padding to preserve overall timing
Transition paddingSet the padding in frames
Preview transitionInclude transitions in storyboard playback
Print transition notes inChoose where transition notes are printed

The description for using no padding says shot positions stay unchanged, and transitions require extra animation before and after shots.

Printing transitions on the storyboard

Section titled “Printing transitions on the storyboard”

Transition panels is in the storyboard panel settings (gear icon). When it is on, the printed storyboard gains one panel-sized cell between shots that carries the transition’s symbol and full name. When it is off, transitions do not appear on the sheet.

Extra animation for transitions

Section titled “Extra animation for transitions”

Transitions need material around the join. Extra frames records the required amount for each shot, while Ordered in and Ordered out record the amounts ordered for each side. The built-in description identifies these as extra animation around a shot and describes the requested amount as an optional production note.

ControlPurpose
Extra framesExtra animation frames required for the shot
Ordered in / Ordered outFrames ordered for each side
RequestedRequested amount as an optional production note
Set order / Set requestEnter ordered or requested amounts
Use minimum / Order minimumUse the calculated minimum amount
Undecided: adopt the calculated minimumLeave the amount unspecified and use the minimum

No extra frames needed indicates that no extra frames are required. Minimum unknown indicates that the minimum cannot be calculated.

When a reorder breaks the anchor

Section titled “When a reorder breaks the anchor”

A transition is attached to the two shots on either side of it. Reordering or deleting shots can change what it is attached to. Expected neighbour and Current neighbour show the discrepancy, and one of the following resolves it.

ControlPurpose
Accept new neighbourRebind the transition to the current arrangement
Keep unresolvedLeave it undecided
Keep as instructionKeep it as a production instruction rather than a transition

Missing shot indicates that the shot it referenced is gone. An Instruction only transition carries no artwork or duration.

Placement and material

Section titled “Placement and material”
ControlPurpose
Offset from shot startHow many frames into the shot the transition sits
Frames before anchorFrames taken ahead of the anchor point
Endpoint heldHold the endpoint frame to extend playback time
Project edge / Project endHow the edge of the project is treated as a neighbor
Print note inChoose where the note is printed

When material is short, the shortfall is reported by stage as Preview short by N frames, Order short by N frames, or Delivery short by N frames. min +N frames and available +N frames give the required minimum and what is currently available. Some types or shapes report Preview unavailable for this type or shape.

When something is missing or does not work

Section titled “When something is missing or does not work”
  • A message says extra animation is required for transitions before export: Material is missing around the join. Check Extra frames and arrange the incoming and outgoing amounts.
  • The overlap is shorter than requested: The message states that shot length limits the overlap to N frames. The neighboring shots’ lengths limit the overlap.
  • Overall timing changes: Use the option to pad new transitions to preserve timing in Global transition settings.

Notes

Section titled “Notes”
  • Hands-on verification on build 568 confirmed the entry point, the list of types, placement in the Transition row, and how transitions appear on the printed storyboard.
  • Length (frames), Wipe shape, Fade-in start / Fade-out end, Global transition settings, and the extra-animation ordering controls are based on the implementation and built-in translations; their on-screen locations and results remain unverified.
