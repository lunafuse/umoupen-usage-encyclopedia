Use the Gallery

Content checked: Umoupen 0.9.51 build 542 (2026-08-28)

Use the list, preview, tags, and search to find reusable assets.

Find reusable Symbols, Drawings, Images, Media, Models, and other assets, then place them on the Stage.

Gallery, Add to Gallery, Convert to Native, Mark as Actor, Claim Ownership

Location: Panels → Show Panels → Gallery

Shortcut: ⌘G (macOS) / Ctrl+G (Windows): Convert selection to a Symbol (Add to Gallery)

Basic steps

Section titled “Basic steps”
  1. Choose Panels → Show Panels → Gallery.
  2. Find an asset using the list, preview, tags, or search.
  3. Drag the asset onto the Stage.

To convert selected Stage content to a Symbol, select it and choose Add to Gallery from the right-click menu. You can also press Cmd+G (Ctrl+G on Windows). Although the command says “Add,” it creates a Symbol and replaces the Stage selection with an instance. To convert an entire Layer, see Create and reuse symbols.

Controls at the top of the panel

Section titled “Controls at the top of the panel”
NameWhat it does
ListSwitches between list and thumbnail views.
PreviewShows a preview of the selected asset.
Add TagsAdds tags used to find assets.
SearchFilters assets by name or tag.

At the bottom of the panel, you can sort by Name, check the asset count, and adjust the thumbnail size.

Main items

Section titled “Main items”
ItemWhat it does
Asset listShows reusable assets. When there are no assets, instructions for adding them appear in the center.
Drag to the StagePlaces an instance or copy.
Show in GalleryShows the source data for a placed Symbol.
Edit in PlaceEdits the source data while showing the surrounding contents.

What happens at each drop target

Section titled “What happens at each drop target”
Drop targetResult
StagePlaces a Symbol or another asset. Place Symbols on a Vector Layer.
Reference panelAdds a Symbol as a reference asset.
Stage (Audio asset)Creates an Audio Layer.
Outside UmoupenExports the asset in a form that can be used elsewhere. Some assets cannot be exported because of their type or license.

If the message “Symbols can only be added to Vector Layers” appears when you place a Symbol, select a Vector Layer and drag it again.

Right-click an asset

Section titled “Right-click an asset”

The available items depend on the asset type.

AssetMain operations
General assetRename, duplicate, edit, open externally, export, or delete
ScriptEdit Script or Apply Script
Convertible assetConvert to a native Umoupen asset
Character assetMark as Actor
Shared assetClaim Ownership or Request Ownership

For organizing names, Folders, Tags, and storage locations, see Organize the Gallery.

Related articles

Section titled “Related articles”
  • Organize the Gallery
    Organize Gallery assets by name, Folder, and storage location.
  • Create and reuse symbols
    Convert artwork or animation into a Symbol and register its reusable source in Gallery. Umoupen provides Add to Gallery and Convert Layer to Symbol. Both create a Symbol; the difference is the scope they convert.
  • Market
    Use this panel to find and download Brushes, Palettes, Effects, Textures, Templates, and Symbols, or publish your own assets.
