Curve Editor

Verification record: Umoupen 0.9.59 build 628 (2026-10-05) · Verification scope

The Curve Editor adjusts how tween values change using curves. Easing describes how a change progresses over time between keys. You can keep the start and end positions while making motion start slowly or slow down near the end.

Curve Editor, Edit Tween Curve, speed graph, easing, Reset Handles, Smooth Handles, Linear Segment, Remove Point, Properties, Layer Transform, Layer Opacity, Layer Tint, Position X, position curve missing, x / y curves

Location: Timeline → Tween Editor / Curve Editor

What you need first

Section titled “What you need first”
  • A Symbol or Text object with at least two tween keys. To move a whole layer, a layer with keys on Layer Transform or a similar layer value
  • An interval where Tween is enabled in the Timeline

If there is no motion yet, first create the start and end states in Tween.

Adjust one property at a time

Section titled “Adjust one property at a time”
  1. Select the layer containing the Tween you want to adjust.
  2. Open the Tween Editor and show the Curve Editor.
  3. In the Properties list, choose one property to adjust. Symbol values are under the Symbol name heading; whole-layer values are in the upper part.
  4. Select the line between two keys or select a key, then move its curve handles or control points.
  5. To keep the start and end states, leave the endpoint keys in place and adjust the handles between them.
  6. Play the interval and make small adjustments until the timing is right.

Example: start slowly

Section titled “Example: start slowly”

This comparison changes the same Symbol’s Position X from Linear to Ease In. The start remains on frame 17 and the end on frame 57.

  1. Move the playhead between the two keys.

Read the Properties list

Section titled “Read the Properties list”

The Properties list on the left of the Tween Editor shows every tweenable value of the selected layer in one list. The upper part holds values for the whole layer; the lower part holds values for each Symbol placed on the layer.

PartItemsWhat moves
UpperLayer Opacity, Layer Tint, Layer Transform (Position X / Position Y / Scale X / Scale Y / Rotation / Skew)The whole layer
LowerUnder each Symbol name heading: Position / Scale / Rotation / Skew / VisualThe Symbol under that heading

The upper items are always listed, even without keys. Global sits to the right of the list heading, and Ease sits at the right of each row.

Position X and Position Y appear in both parts. To refine a Symbol’s motion, open Position under that Symbol’s name heading. Selecting a Symbol on the canvas or a layer row in the Timeline does not change the list.

Colors belong to the kind of item, not to the Symbol that owns it. For example, the Layer Transform heading and a Symbol’s Position are both orange.

Read the curve

Section titled “Read the curve”

The image shows Global easing. To examine a specific position, scale, or rotation value, select that property in the list.

  • In a property curve, the horizontal direction represents time and the vertical direction represents the selected value.
  • A steep segment changes the value more over a short time, while a flat segment changes it less.
  • Start with position alone, then move to scale or rotation. This makes it easier to identify which curve affects the motion.

Key modes

Section titled “Key modes”
ModeUse
Simple Tween KeysAdjust the overall motion using only the main keys.
Property Tween KeysManage keys separately for each property.
Custom CurveAdjust the curve for each interval directly.

Switch between key modes with Advanced Tween Keying and Simple Tween Keys on the Timeline toolbar.

Use Clear Current Tween Point, Move Tween Keys, and Delete Tween Keys to organize the keys.

When you right-click a point

Section titled “When you right-click a point”

Right-click a point on the curve and the menu offers items that adjust only that point.

ItemWhat it does
Reset HandlesReturns the curve handles to their starting direction and length.
Smooth HandlesLines up the handles on both sides of the point so the curve passes through without a corner.
Linear SegmentMakes the segment next to the point a straight line instead of a curve.
Remove PointDeletes the selected point; the same item removes several selected points.

If it does not work

Section titled “If it does not work”
SymptomCheck this first
No curve or key appearsSelect the layer that holds a Symbol or Text object with a Tween, then expand its row.
You cannot find a Symbol’s position curveWhen the panel under the Tween Editor is short, only the upper part of the list (whole-layer values) is visible. Make the panel taller or scroll the list, then open the Symbol name heading.
The curve label is an upper-part name such as Layer Tint / AmountYou are looking at a whole-layer value. To move a Symbol, choose an item under its Symbol name heading.
You cannot tell where to move a handleShow one property, then select a key or the line between two keys.
There are too many lines to identify the active oneShow and adjust position, scale, and rotation one at a time.
Editing the curve does not change the motionConfirm that Tween is enabled in the Timeline and that the playback range contains both keys.
You deleted too many keysUndo immediately, then confirm the property and selected keys before deleting again.

Related articles

Section titled “Related articles”
  • Animate symbols, text, and layers with Tween
    Tween creates motion by automatically filling in values between specified times. A keyframe (key) records values such as position, scale, or rotation at a particular time. Calculating values between keys is called interpolation. The setup differs for Symbols, Text objects, and whole layers.
  • Sync layer timing in a folder
    Layer timing synchronization keeps frame placement aligned while editing layers directly inside the same folder. It synchronizes timing, such as start positions and exposures, rather than the artwork contents. When lines, color, and shadows are on separate layers, timing edits on one layer can also be applied to the others.
  • Timeline thumbnails, Frame Roller, and range linking
    A thumbnail is a small preview of a drawing. Frame Roller lets you check surrounding drawings in sequence. You can also link the playback range to the content, or use Timeline Tracking to keep the current position visible.
