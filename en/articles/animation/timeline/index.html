Reading the Timeline

Verification record: Umoupen 0.9.59 build 628 (2026-10-05) · Verification scope

Use the Timeline to choose which frame on which layer you want to edit. Layers run vertically and time runs horizontally. See Frames, drawings, cels, and exposures for the distinction between units of time, artwork, and the intervals in which artwork is shown.

Timeline, Timeline Bottom Toolbar, Show Timeline, Separate Timeline Window, external timeline, detached timeline, F9, dope sheet, Play Animation, Auto Height, Extend Layer Colors, Project Notes, Note Select, Short Layers

Layer rows are on the left and the frame ruler is above them. The vertical blue band marks current frame 1; the horizontal blue span and its diamond endpoints mark a tween.

Location: Panels → Show Panels → Timeline

Basic layout

Section titled “Basic layout”
AreaMeaning
Rows on the leftLayers. Each layer has one row.
Numbers at the topFrame numbers. Divisions in seconds are also shown.
CellThe position where a layer and frame intersect.
Blue cellThe currently selected layer and frame.
Vertical position indicatorShows the current playback position and playback range.
Buttons at the bottomControl playback, add or duplicate frames, adjust exposure length, and perform other actions.

Click the cell you want to edit.

The cell turns blue, and drawing and frame operations now apply to that layer and frame.

Drag to select a range of cells. You can then move, copy, cut, paste, reverse, clear, or delete the selection.

Layer rows on the left

Section titled “Layer rows on the left”

Only the states available to a layer appear beside its name.

ControlWhat it does
Expand / CollapseExpands or collapses the contents of a folder
Clipping Mask / EffectsShows and toggles clipping and indicates whether effects are present
Use Camera ViewShows contents from outside a Camera Folder while keeping only the Camera selectable
Solo / Lock / ShowShows the layer alone, locks editing, or shows and hides the layer
Mute Audio LayerMutes an Audio Layer
100%Sets the volume of an Audio Layer

You can rename a layer in place. Drag a row vertically to reorder it, or drag a folder’s time interval horizontally to move its Folder Timing.

Some controls may be hidden through Customize Toolbar. See the relevant article for detailed frame operations. For storyboard controls, see Reading the Storyboard Timeline.

Move the Timeline to a separate display

Section titled “Move the Timeline to a separate display”

Use Separate Timeline Window to move the Timeline or Timesheet into its own window and place it on another display. The build 581 official announcement lists F9 as the default shortcut. If it does not respond, check the current assignment under Keybinds.

The build 581 announcement described the detached window as a work in progress with some features missing. If a needed operation is unavailable in the detached window, return to the regular Timeline.

If you cannot find the Timeline

Section titled “If you cannot find the Timeline”

Choose Panels → Show Panels → Timeline from the top menu.

View drawings as thumbnails

Section titled “View drawings as thumbnails”

Press Shift+T to show a drawing thumbnail inside each cell. Press it again to return to the standard view.

See Timeline thumbnails, Frame Roller, and range linking for guidance on choosing between thumbnails, Frame Roller, and animation range linking.

Related articles

Section titled “Related articles”
  • Frames, drawings, cels, and exposures
    The Timeline treats time, artwork, and the duration for which artwork is shown as separate things. Frame rate (fps) is the number of frames per second; it relates a frame count to a duration in time.
  • Blank and duplicate frames
    Use New Blank Frame to start with empty artwork, or Duplicate Frame to build on the current artwork. Both command names contain “Frame,” but each creates a new drawing on the selected layer.
  • Playback, looping, and playback range
    A playback range is the interval between the start and end of playback. Looping repeats the target by returning to its beginning. The Timeline’s playback range and each layer’s repeat settings are separate controls.
  • Timeline thumbnails, Frame Roller, and range linking
    A thumbnail is a small preview of a drawing. Frame Roller lets you check surrounding drawings in sequence. You can also link the playback range to the content, or use Timeline Tracking to keep the current position visible.
