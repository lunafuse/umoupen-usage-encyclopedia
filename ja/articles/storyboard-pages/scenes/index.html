シーンでカットをまとめる

本文確認：Umoupen 0.9.56 build 570（2026-09-07）

絵コンテタイムラインで選んだカットを一つのまとまりにします。まとまりの呼び名と、カット番号の数え方は用語と番号付けで決めます。

Add Scene、New Scene、Group into Scene、Ungroup Scene、Split Scene、Rename Scene、Delete Scene、Hide Scene、Show Scene、Lock Scene Length、Scene Options、Scene Thumbnail Grid、Play Scenes、Previous Scene、Next Scene、Terminology、Numbering、Lock shot numbers、Renumber shots in current order、Accept new neighbour、Missing shot、シーン、シーンにまとめる、シーンのグループ化を解除、シーンを分割、シーン名を変更、シーンを削除、シーン設定、シーンを再生、用語、番号付け、カット番号をロック、番号を振り直す、group shots into scenes、隣接カット、シーン に まとめる、シーン の グループ 化 を 解除、シーン を 分割、シーン 名 を 変更、シーン を 削除、シーン 設定、シーン を 再生、番号 付け、カット 番号 を ロック、番号 を 振り 直す、隣接 カット

場所： 絵コンテパネル（絵コンテ）→ 設定 → 用語／番号付け

用語で呼び名が変わる

Section titled “用語で呼び名が変わる”

用語は、絵コンテパネルの設定（歯車）にあります。階層の呼び名を切り替えます。

選択肢上段中段
シーン / カットシーンカット
シーケンス / シーンシーケンスシーン

階層は3段で、上段がまとまり、中段が絵コンテタイムラインに並ぶ単位、下段がコマです。下段はどちらの選択肢でもパネルです。

呼び名が変わるだけで、操作の中身は同じです。 中段の追加・分割・名前の変更・削除・表示の切り替え・長さのロック・設定・サムネイルのグリッド・前後の移動・再生は、用語を変えても同じ操作で、カットを追加・削除・分割するとカットの長さと再生範囲で説明しているものです。この記事では扱いません。

この事典の本文は、アプリの組込み日本語表示にそろえて中段を「カット」と書いています。

まとめる・解く

Section titled “まとめる・解く”

絵コンテタイムラインで複数のカットを選んでから右クリックすると、メニューの先頭に次の2つが出ます。カットを1つだけ右クリックしたときは出ません。

項目できること
カットをシーケンスにグループ化選んだカットを一つのまとまりにする
シーンのグループ化を解除まとまりを解いて個々のカットへ戻す

この2つは呼び名が食い違っています。 作る側は「シーケンス」ですが、できあがったまとまりは絵コンテタイムラインにシーン 1として表示され、解除する側も「シーン」です。番号付けの説明でも、どのまとまりにも属さないカットを「グループ化されていないカット」として扱い、まとまりをシーンと呼んでいます。まとまりの実体はシーンで、作る操作の表示だけがシーケンスになっていると読むのが自然です。

組込み翻訳には「シーンにまとめる」という別の語も登録されていますが、この画面では使われていません。対応する英語キーは記事末尾の組込み翻訳に載せています。用語プリセットを切り替えたときに表示が変わるかは未確認です。

まとまりは、カットの行の上に帯として表示され、帯の右端にメニューボタンがあります。

まとまりを対象にした操作は、まとめる・解く・名前を変えるの3つだけです。 長さのロックや再生といった操作は中段のカットに対するもので、まとまりには用意されていません。

基本の使い方

Section titled “基本の使い方”
  1. 絵コンテタイムラインで、まとめたいカットを複数選びます。
  2. 右クリックしてカットをシーケンスにグループ化を選びます。
  3. まとまりを解くときはシーンのグループ化を解除を選びます。

成功すると： 選んだカットの上にシーン 1という帯が表示され、そのカットがまとまりとして扱われます。

番号付け

Section titled “番号付け”

番号付けは用語のすぐ下にあり、カット番号をどの単位で数えるかを選びます。

選択肢数え方
エピソード作品全体で通し番号にする
シーンシーンごとに番号を振り直す

同じ設定に、次の2つが並びます。

項目できること
カット番号をロック並べ替えても番号を変えないようにする
現在の順序でカット番号を振り直す今の並び順に合わせて番号を付け直す

範囲を選んで振り直すときは「選択した範囲の既存カット番号を振り直します。元に戻すと以前の番号に戻ります。」と示されます。シーンごとに振り直す方式では「S1-C001、S2-C001… シーンごとに番号を振り直します。元に戻すと以前の番号に戻ります。グループ化されていないカットはS0になります。」となり、どのシーンにも属さないカットは S0 になります。

隣り合うカットの照合

Section titled “隣り合うカットの照合”

まとまりやカットを並べ替えると、隣接関係が想定と変わることがあります。そのときは想定される隣接カットと現在の隣接カットが示され、新しい隣接カットを承認で今の並びを正とします。対象のカットが見つからない場合はカットが見つかりませんと表示されます。

見つからない・動かないとき

Section titled “見つからない・動かないとき”
  • 右クリックしてもグループ化が出ない：カットを1つだけ右クリックしたときのメニューには出ません。まとめたいカットを複数選んでから右クリックします。
  • 「シーンにまとめる」という項目が見つからない：この画面での表示はカットをシーケンスにグループ化です。作る側だけ呼び名が違います。
  • 番号が変わってしまう：カット番号をロックを使います。振り直しは元に戻すで以前の番号へ戻せます。
  • まとめたのにカット番号が S0 のまま：番号は自動では振り直されません。現在の順序でカット番号を振り直すを実行します。アプリの説明では S0 は「グループ化されていないカット」を指すので、まとまりの中のカットが S0 のままなのは番号が古いままという意味です。
  • シーンの番号が並び順と合わない：既存のシーンの間に新しくシーンを作ると、シーン 2、シーン 1 のように作った順の番号が並び順と食い違ったまま残ります。番号は作成順に振られ、位置では振り直されません。

補足

Section titled “補足”
  • 用語と番号付けが絵コンテパネルの設定（歯車）にあること、選択肢の内容、カット番号をロックと現在の順序でカット番号を振り直すが同じ設定に並ぶことは build 568 の実画面で確認しました。
  • カットを1つだけ右クリックしたメニューにはまとめる操作が含まれず、複数選んで右クリックするとメニュー先頭にカットをシーケンスにグループ化とシーンのグループ化を解除が現れることを実画面で確認しました。できあがったまとまりがシーン 1という帯で表示されることも確認しています。
  • カット番号がまとめた時点では振り直されないことと、間に作ったシーンの番号が並び順と一致しないことは利用者の実画面での確認です。振り直しの実行後にどうなるかは未確認です。
  • 用語の選択肢は build 570 の実画面で確認しました。build 568 では同じ設定が実写・アニメーション・日本語の3つのプリセットとして表示されていましたが、570 では階層の呼び名2つになっています。組込み翻訳には実写・アニメーション・日本語と3通りの階層表記がいずれも残っており、文字列の増減はないため、表示の出し分けだけが変わったものです。
  • 中段の操作が呼び名を変えても同じであることは、まとまり側にだけ追加・分割・削除などが存在しないことから読み取ったもので、画面で用語を切り替えて確かめてはいません。

関連記事

Section titled “関連記事”
  • カットを追加・削除・分割する
    絵コンテタイムラインへカットを増やし、不要なカットを消し、再生ヘッドの位置で二つに分けます。
  • カットを並べてシーケンスにまとめる
    カットの順序を変え、関連するカットを名前付きシーケンスへまとめます。
  • カット間のトランジション
    隣り合うカットのつなぎ目に、オーバーラップやフェードなどのトランジションを置きます。トランジションの種類と長さを決め、つなぎに必要な追加アニメーションの枚数を記録します。

確認情報

Section titled “確認情報”
  • 利用者の実画面で確認：用語の選択肢が「シーン / カット」と「シーケンス / シーン」の2つになっていることを確認した。build 568では同じ設定が実写／アニメーション／日本語の3つのプリセットとして表示されていた。複数のカットを選んで右クリックすると、メニューの先頭に「カットをシーケンスにグループ化」と「シーンのグループ化を解除」が現れ、実行するとカットの行の上に「シーン 1」という帯が表示される。帯の右端にメニューボタンがある。作る側の表示だけが「シーケンス」で、解除と帯の表示は「シーン」である。まとまりを作った直後もカット番号のS部分はS0のまま残り、既存のシーンの間に新しくシーンを作ると並び順に対してシーン 2、シーン 1という順で番号が残る。この確認時は「カット番号をロック」がONで「現在の順序でカット番号を振り直す」は選択できない状態だった。
  • 現行実装から確認：build 568→570の差分では、組込み翻訳の追加は3件（Export Book as PDF、Export every page as a PNG image、Linear Segment）で削除0、日本語表示の変更0である一方、実装は2,097件変わっている。実写・アニメーション・日本語の3語と、3通りの階層表記はいずれも570に残っている。用語の選択肢が2つになったのは文字列の増減ではなく表示の出し分けの変更である。差分ツールの影響記事28件にSTB-014とSTB-015は含まれず、この変更は画面でしか検出できなかった。
  • 未確認：用語を切り替えたときにグループ化・解除やタイムラインの表示がどう変わるか。まとまりの帯の右端にあるメニューの中身。「カット番号をロック」をOFFにして「現在の順序でカット番号を振り直す」を実行した後にS番号とシーン番号がどうなるか。
  • 証拠記録：F-20260907-007
