トゥイーンでシンボル・テキスト・レイヤーを動かす

確認記録：Umoupen 0.9.61 build 652（2026-10-17） · 確認範囲

トゥイーンは、時刻ごとに指定した値の間を自動で補い、動きを付ける機能です。キーフレーム（キー）は、特定の時刻の位置・拡大率・回転などを記録した点です。キーの間の値を求めることを補間と呼びます。シンボル・テキスト・レイヤーでは、キーを作る手順が異なります。

動かす対象設定する場所
シンボル・テキストトゥイーンをONにし、1つのフレームの露出内にキーを追加
レイヤー全体移動のプロパティでレイヤーを選び、アニメートをON

シンボル・テキストのトゥイーンは、配置したオブジェクトの値を変えます。別々の描画の中割りは生成しません。

キーを記録する対象は、シンボルのインスタンス、文字オブジェクト、またはレイヤーです。

場所： タイムライン → トゥイーン／トゥイーンエディタ

ショートカット（macOS）： ⌘T（トゥイーンエディタ）

ショートカット（Windows）： Ctrl+T（トゥイーンエディタ）

二つのエディタを使い分ける

Section titled “二つのエディタを使い分ける”

トゥイーンエディタを開くと、プロパティの一覧と編集領域が現れます。その編集領域をキーフレームエディタとカーブエディタで切り替えます。

表示画面で読むもの使う場面
キーフレームエディタプロパティごとの行と、キーのあるコマを示すひし形どの項目に、いつキーがあるかを確認し、キーを移して時刻を変える
カーブエディタ時間に沿った値の曲線、またはイージングの曲線値が増減する区間や、変化の緩急を確認・調整する

同じトゥイーンを二つの表示で見る

Section titled “同じトゥイーンを二つの表示で見る”

以下は、同じレイヤーのSymbol 23を37コマ目で表示した比較です。既存のキーは17・57コマ目にあります。

キーフレームエディタ

横方向はコマ位置です。縦に並ぶのは位置、スケール、回転などの項目で、ひし形の高さは数値の大小を表しません。キーを右クリックすると、コピー・切り取り・貼り付け・削除のメニューが出ます。

カーブエディタ

Symbol 23 → 位置 → Xを選ぶと、グラフに値: Symbol 23 / 位置 Xと表示されます。こちらは縦方向が数値です。赤い曲線が下がっているのはXが小さくなることを表し、終点へ向けて傾きが緩くなる部分では、Xの変化も小さくなります。

キーを移して、変化が終わるコマを変える

Section titled “キーを移して、変化が終わるコマを変える”

上の例で位置 → Xを選び、キーフレームエディタの57コマ目のキーを49コマ目へドラッグした結果です。

Xの終点の値を保ったまま、そこへ到達するコマが早まります。スケールや回転などのキーは57コマ目に残るため、どの項目のキーを選んだかが重要です。項目の変化を早く終わらせたい、ほかの項目と時刻をずらしたい場合に使います。

始点と終点のコマを保って途中の進み方を変える場合は、カーブのハンドルを調整します。

動きを作ってから緩急を整える

Section titled “動きを作ってから緩急を整える”
  1. 下の手順で開始・終了のキーと位置を決めます。
  2. キーフレームエディタで、対象のシンボル名とキーのあるコマを確認します。
  3. カーブエディタへ切り替え、同じシンボルの調整したい項目を選びます。
  4. 出だしだけを遅くしたい場合は、位置Xのイージングを変える例へ進みます。

エディタの切替は表示方法の切替です。トゥイーンのON／OFF、キーの管理単位を切り替えるキーモードとは別の操作です。

まず用意するもの

Section titled “まず用意するもの”

シンボル・テキストを動かす場合は、次の2つを用意します。

  • ステージへ配置したシンボル、またはテキスト
  • 2セル以上に伸ばした1つのフレームの露出

手元の絵を動かす場合は、先にシンボルを作る・再利用するでシンボル化します。

シンボルを左から右へ動かす

Section titled “シンボルを左から右へ動かす”

キーの追加には、タイムライン左下の丸い「＋」を使います。

  1. ギャラリーからシンボルをステージへ配置します。
  2. タイムラインで対象のフレームを選び、4を押して右へ伸ばし、露出を2セル以上にします。新しいフレームは追加しません。
  3. 露出の先頭セルで移動を選び、開始位置を決めます。
  4. タイムラインのトゥイーンをONにします。⌘T／Ctrl+Tはトゥイーンエディタの表示切替であり、トゥイーン自体のON／OFFではありません。
  5. 同じ露出内の後ろのセルへ再生位置を移します。先頭セルや露出の外側にはキーを追加できません。
  6. トゥイーンキーフレームを追加を選び、移動またはプロパティでシンボルを終了位置へ動かします。
  7. 区間をスクラブまたは再生します。青い帯と両端のひし形が表示され、途中のセルで位置が連続的に変われば成功です。
  8. 途中にも状態を加える場合は、同じ露出内の別のセルでキーを追加して値を変えます。

使用例：同じ絵を左から右へ動かす

Section titled “使用例：同じ絵を左から右へ動かす”

プロジェクトのシンボルに、17コマ目の左端と57コマ目の右端のキーを置いた例です。途中の位置はトゥイーンで補間されます。右端で少し止まり、同じ動きを2回再生します。

レイヤー全体を動かす

Section titled “レイヤー全体を動かす”

シンボルにしなくても、レイヤー全体の位置・拡大率・回転をキーで動かせます。値はトゥイーンエディタのレイヤー変形（位置 X／位置 Y／スケール X／スケール Y／回転／スキュー）に入ります。

  1. 移動を選び、プロパティでレイヤーを選びます。
  2. 同じプロパティのアニメートをONにします。
  3. キーを置きたいフレームへ再生位置を移し、レイヤーをドラッグして移動・回転・拡大縮小します。ドラッグすると現在のフレームにキーが入ります。
  4. 別のフレームでも同じ操作をして、区間を再生します。

アニメートがOFFのときのドラッグは、キーを打たずにレイヤーの基本の位置を変えます。すでにキーのある値は、キーの値が使われます。

キーを消すときは、レイヤーを1つだけ選んで右クリックし、変形の親のサブメニューから変形キーをクリアを選びます。同じサブメニューのトランスフォームリセットは、レイヤーを描いた位置へ戻し、移動・回転・拡大縮小とキーを解除します。ピボットと変形の親はそのまま残ります。

右クリックメニューの先頭に「3 選択レイヤー」のように数の付いた表示が出ているときは、複数のレイヤーが対象になっていて、変形の親の項目が出ません。タイムラインの範囲選択を外し、レイヤーを1つだけ選び直します。レイヤーのタイミングを同期したフォルダーの中では、子レイヤーを1つだけ選べないので、先にフォルダーの同期をオフにします。

うまくいかないとき

Section titled “うまくいかないとき”

シンボル・テキストのトゥイーンでは、次の条件を確認します。

症状確認すること
トゥイーン操作が使えないシンボルまたはテキストを選びます。ラスターレイヤーそのものにはシンボル用のトゥイーン操作を使えません。
キーを追加できない1つのフレームの露出を2セル以上に伸ばし、先頭以外のセルへ移動します。
再生しても動かない新しいフレームを作らず、同じ露出内に開始と終了の異なる値を置いたか確認します。
⌘T／Ctrl+Tを押しても動かないこのショートカットはエディタの表示切替です。タイムラインのトゥイーンを別にONにします。

ラスターレイヤーでは、レイヤーエフェクトを追加した場合に効果の設定値がトゥイーン対象になります。

コマ打ちのように見せる

Section titled “コマ打ちのように見せる”

ステップトゥイーンをONにすると、補間の値を毎コマではなく数コマおきに更新し、2コマ打ちや3コマ打ちに近い動きにします。キーの位置と値は変わりません。

切替時はステップトゥイーン（オン）またはステップトゥイーン（オフ）と表示されます。

トゥイーン点を移し替える

Section titled “トゥイーン点を移し替える”

作った補間点は、切り取って別の位置へ貼り付けられます。

  1. トゥイーンエディタで対象のトゥイーン点を選びます。
  2. トゥイーン点を切り取りまたはトゥイーン点をコピーを実行します。
  3. 移したい位置へ再生位置を移し、トゥイーン点を貼り付けを実行します。

点を選ばずに実行すると先にトゥイーン点を選択してください、貼り付ける内容がないときは貼り付けるトゥイーン点がありませんと表示されます。レイヤーエフェクトの補間点も、同じ操作をエフェクト点として行えます。

トゥイーンキーをまとめて移し替える

Section titled “トゥイーンキーをまとめて移し替える”

複数のトゥイーンキーは、時間間隔を保ったまま別のフレームへコピーまたは移動できます。

  1. トゥイーンエディタで対象のトゥイーンキーを選びます。
  2. キーを残す場合はコピー、元の位置から移す場合は切り取りを実行します。
  3. コピーしたキーがすべて入る余裕のあるフレームへ再生位置を移します。
  4. 貼り付けを実行し、キーの間隔と値を確認します。

キーが未選択なら先に補間キーを選択してください、貼り付ける内容がなければ貼り付ける補間キーがありませんと表示されます。配置先の尺が足りない場合は、コピーした補間キーがすべて収まるフレームを選択してくださいと表示されます。

主な操作

Section titled “主な操作”
操作働き
トゥイーン補間そのものをON／OFFします。
トゥイーンエディタキーと補間区間の編集表示を開閉します。
トゥイーンキーフレームを追加現在位置へトゥイーン用のKeyを追加します。
フレームに変換：タイムラインでトゥイーンのある範囲を右クリックすると出ます。シンボルのトゥイーンを通常のフレームへ変換します。変換できるのはシンボルのトゥイーンキーだけです。
トゥイーンキーを消去補間点を消します。
ステップトゥイーン補間の更新をコマ単位で間引き、コマ打ちのような見え方にします。
トゥイーン点を切り取り／トゥイーン点を貼り付け選んだトゥイーン点を別の位置へ移します。
トゥイーンキーを切り取り／コピー／貼り付け選んだキーのまとまりを別のフレームへ移します。
変形キーをクリアレイヤーを1つだけ選んで右クリックしたときの変形の親のサブメニューに出ます。レイヤー全体の位置・拡大率・回転のキーを消します。

動きの速さを調整する

Section titled “動きの速さを調整する”

基本の移動ができた後で、カーブエディタを使うと、キー間の加速、減速、溜め、行き過ぎを調整できます。カーブエディタは最初のトゥイーンを作るための必須工程ではありません。

数値プロパティへノイズを加える

Section titled “数値プロパティへノイズを加える”

ノイズは、設定値へ揺らぎを加える調整です。ここでは動きの経路そのものではなく、選んだ数値プロパティへ加えます。

  1. トゥイーンエディタで、レイヤーの不透明度などの数値プロパティを選びます。
  2. エディタ下部の波形ボタンでNoise Modifierを有効にします。
  3. 表示されるAmpと速度で、揺らぎの量と速さを調整します。
  4. 同じフレームで有効・無効を切り替え、カーブと対象の表示を確認します。

Layer 11の不透明度では、有効時に背景の猫と周辺描画が消えたフレームで、無効にすると元の表示へ戻りました。不透明度など表示を大きく変えるプロパティでは、値のカーブも合わせて確認します。

関連記事

Section titled “関連記事”
  • 露出の長さと位置を変える
    露出は、一つの描画を表示する区間やその長さです。露出を伸ばすと同じ描画の表示時間が長くなり、開始位置を動かすと表示を始める時刻が変わります。描画の内容を変えずにタイミングを調整できます。
  • カーブエディタ
    カーブエディタは、トゥイーンの値の変化を曲線で調整する画面です。イージングは、キー間の変化が時間に沿ってどのように進むかを表します。開始と終了の位置を保ちながら、出だしを遅くする、後半で減速するといった変化を付けられます。
  • シンボルを作る・再利用する
    シンボルは、絵やアニメーションを再利用するための素材です。ステージに配置した一つひとつをシンボルインスタンスと呼びます。
  • 移動・変形する
    変形は、アートワークの位置、大きさ、角度、傾きを変える操作です。選んだ絵だけを動かす内容と、レイヤー全体を動かすレイヤーを使い分けます。変形の中心になる点をアンカーまたはピボットと呼びます。
