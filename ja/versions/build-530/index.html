変更点

Section titled “変更点”

日本語表示名

Section titled “日本語表示名”

build 530の実行ファイルに組み込まれた英日対応3,446件を表示名の正本として、利用者向け128ファイルの本文、画面上の場所、ショートカット名を再監査しました。登録キーとファイルの組1,887件を対応する日本語表示へ更新し、可視表示に残る登録済み英語キーは0件です。

各機能記事には英語キーとの対応を検索用情報として保持しています。現在の組込み表に登録がない画面表示は、画面と同じ英語名を使います。

設定・認証・診断

Section titled “設定・認証・診断”

設定画面の見方では、ファイル25群、表示26群、パネル7群の全58群について、設定内容と表示条件を説明しています。

ライセンス認証と端末管理へファイルメニューからマイデバイスを開く経路を追加しました。診断と保存失敗レポートでは、問題の再現後に診断記録をオフにする手順を明記しました。

画面部品coverage監査

Section titled “画面部品coverage監査”

記事数とは別に、現行画面の各操作部品が記事本文へ収録されているかを検査しています。

ツールバーの13グループ83項目（表示55、非表示28）を一つずつ機能記事へ割り当てました。Panel Tool、Book Margins、3D用ツールバー、色操作、タイムライン下部操作列、追加可能なパネルボタンまで収録済みです。

現行Panel 23面、タイムライン系3面、Properties 36状態、Settings 58群、主要ダイアログ10面、読み込み10経路群、書き出し範囲12コマンド、Command・検索・Shortcutを専用検収表で確認しました。公開ショートカット索引は、既定割当261件を利用者向け137行に整理しています。

画面の見取り図

Section titled “画面の見取り図”

機能名・画面から探すの冒頭に、現行画面を7区画に分けた見取り図を追加しました。画面の場所から既存の機能記事へ進めます。

パネル

Section titled “パネル”

編集用のパネル検収表に23面を登録しました。各パネルの固定部品に加え、レイヤー種類別メニュー、ページ操作、ナビゲーターのビュー選択、ギャラリーの素材別メニューとドラッグ先、カラー操作を収録しています。

タイムライン・プロパティ・設定

Section titled “タイムライン・プロパティ・設定”

タイムライン、タイムシート、絵コンテタイムラインの固定表示と操作、プロパティのツール・レイヤー・選択状態、設定と主要ダイアログを状態別に収録しました。

読み込み・書き出し・ショートカット

Section titled “読み込み・書き出し・ショートカット”

画像、制作ファイル、音声、動画、3D、ブラシ、パレット、効果、シンボル、テキストの入口と対応形式を整理しました。書き出しは範囲、形式、サイズ、透明、カメラ、字幕、下書き、レイヤー、音声などの条件を掲載しています。

現行binaryの222 Actionと261既定割当、16 Key Contextを照合し、ショートカットから探すと検索するを更新しました。

レイヤーパネル上部のアイコン

Section titled “レイヤーパネル上部のアイコン”

レイヤーパネルとアクティブレイヤーに、左から追加、選択、スリム、ラベル、不透明度、下書き、色合い、単独の8項目を収録しました。

ツール別プロパティ

Section titled “ツール別プロパティ”

ツールを選ぶと、右側のプロパティがそのツール用の設定へ切り替わります。ツールバーの見方・カスタマイズから、ブラシ、ペン、消しゴム、塗りつぶし、選択、移動、テキスト、定規などの説明へ進めます。

項目名と表示条件はbuild 530の現行実装で確認し、操作結果を未確認の設定は各記事末尾に示しています。

タップ割り

Section titled “タップ割り”

オニオンスキンの詳細で、前後の絵を個別に移動・回転・拡大縮小し、中割り位置を合わせられます。

build 530を最初の基準点としています。旧buildとの比較調査を行った機能はまだありません。過去buildの資料はbuild 530の仕様として使用していません。
