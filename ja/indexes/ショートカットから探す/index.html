ショートカットから探す

Umoupen 0.9.49 build 530で確認したUmoupenデフォルト初期割当のうち、0.9.50 build 534の通常UIで利用できる機能を掲載しています。同じキーでも、現在の作業状態によって働きが変わります。macOSの⌘に対応するキーは、WindowsではCtrlと表示されます。

割当を変更している場合は、設定（歯車）→ ファイル → キーバインドを編集 → ヘルプ → ショートカットに表示される現在の割当を使います。

プロパティはパネル → パネルを表示 → プロパティで開き、下の描画ツールのキーを押すと、そのツール用のオプションへ切り替わります。

キーが割り当てられていない操作や、現在のツールバーで見えないボタンは、検索 → ツールバーをカスタマイズから表示を確認できます。
